## 1. IA 重构：系统级 vs 项目级功能分区

### 1.1 新导航结构（顶栏分组 + 头像菜单收口）

```text
顶栏（左→右）：LEXFLOW │ 总览 ▾ │ 项目 ▾ │ 协同 ▾ │ 经营 ▾ │ 治理 ▾ │ ⌘K 搜索 │ 铃铛 │ 头像 ▾
  总览 ▾: 驾驶舱、我的工作台
  项目 ▾: 项目全周期、甘特计划
  协同 ▾: 会议中心、出差中心、（申请单）
  经营 ▾: 工时中心、预算管理、费用中心、收款台账、审批中心
  治理 ▾: 质量中心、决策中心、档案中心、权限审计
  头像 ▾: 系统配置中心（仅 sysadmin）、账号设置与改密、退出登录
```

- **系统级功能**（配置中心/账号设置/退出）全部收进头像菜单，顶栏只留业务导航组——顶栏超载与退出溢出根治。
- 角色过滤：无权限的组/项不渲染（如 member 不见治理组的权限审计、经营组的收款台账）。
- 当前组高亮（含子路由命中）；分组下拉键盘可达（方向键/Esc）。
- 项目级内容**只**在左侧「项目索引」与项目空间页签内呈现，与顶栏系统导航不再混排。
- 移动（≤820px）：汉堡抽屉内同样按五组分区呈现；配置入口在抽屉底部。

### 1.2 顶栏防溢出（硬规则）

顶栏内容总宽不得溢出：角色化项数 + 分组下拉保证；回归测试含 1280/1440/1920 三档宽度顶栏无溢出断言（防 09d 类衍生回归）。

## 2. 创建/编辑表单弹窗化（统一规范）

- **规范**：所有「创建/编辑」类操作一律用 Dialog（小型表单）或 Drawer（长表单/带明细编辑器），**禁止内联面板撑开列表页**；弹窗带：标题、字段校验（服务端 fieldErrors 映射）、防重复提交、Esc/遮罩关闭、未保存离开提醒。
- **迁移清单**（现存内联表单全部改造）：/admin 创建用户/创建客户/创建事项/新建模板、/requests 发起申请单、/operations/receipts 登记收款、会议/出差/经费/报销/预算/任务/延期/授权/纪要编辑等创建表单逐一核对（前端会话全量清点）。
- 保持既有可访问性：焦点圈禁、首字段自动聚焦、提交后焦点还原。

## 3. 视觉缺陷修复：按钮重影

- 实证：/admin 用户表「授予/移除/停用」按钮文字叠印（「授疑」「移除用」），疑为按钮内多态文本同时渲染或字重/文本阴影叠加。
- 前端会话根因定位（按钮组件 variants/内容重复渲染）+ 修复 + 全站同类按钮扫描 + 取证截图（修复前后对比）。
