## G2 · IA v2（你给的二选一，我的裁定）

**裁定采用方案 B（顶部功能驱动）**：取消左侧「项目索引」栏；顶栏为唯一功能入口（一级功能），点击展开二级；「项目」一级功能 → 先显示该角色全部项目全周期列表 → 点项目名 → 进项目空间。理由：三区变两区后横向空间全部释放（甘特/台账/表格不再被左栏挤压），与你「功能入口统一在顶部」的心智一致；左栏项目索引的信息（我可见的项目+计数）并入「项目」二级页顶部。

导航组（一级）建议：**总览**（驾驶舱/我的工作台）｜**项目**（项目全周期列表/甘特计划）｜**协同**（会议/出差/申请单）｜**经营**（工时/预算/费用/收款/审批中心）｜**治理**（质量/决策/档案/权限审计/系统配置中心〔sysadmin〕）｜**办公**（见 G3）。

## G3 · 系统级「日常工作/办公」入口 + 自选审批人（后端+前端）

- 顶栏新增「办公」组：**我的申请单**（请假/用章/采购等通用申请的发起+列表）、**通知中心**。请假这类不绑定项目的全局事项从此进入——不再藏总览。
- **自选审批人**（新能力）：审批流节点审批人 kind 增 `initiator_choice`（发起人指定）；通用申请单发起表单在绑定流程含该节点时提供「选择审批人」下拉（user.list）。
- 配套：/admin 审批流里给「请假流程」默认流加 initiator_choice 节点示例（种子）。

## G4 · 审批流设计器优化（前端）

1. **画布放大**：左右面板收窄为可折叠窄条，画布占满中央主区（对标主流流程设计器）。
2. **连接线修复**（你实测的 bug）：连线端点难选中/不支持重连——连线加宽热区、可选中删除、支持从端点重连。
3. **条件节点联动**：按字段类型驱动操作符——金额/数值字段给比较符+阈值；文本/枚举字段给「等于/包含/属于」+文本或下拉值（替换现在「只有比较符+阈值」的形态）。

## G5 · 审批流分级：系统级 + 项目内（后端+前端）

- **系统级流程**（global）：请假/用章等全局流程 + 各 biz_type 默认流，/admin 管理（现状）。
- **项目内流程**（project scope + project_id，引擎已在 03b 落地解析优先级）：项目空间新增「审批流」配置入口（项目负责人可见），项目可建自己的审批流绑定基础表单（出差/延期/经费/费用/工时/会议相关）——固定绑定这些 biz_type，不开放任意对象。
- /admin 审批流列表分「系统级 / 项目内」两区展示。
