# 安全与运维说明（迭代 5 收口）

**维护方：** 后端会话　**日期：** 2026-10-28　**依据：** docs/arch/08 §3/§6

## 1. 会话滑动续期（arch/08 §6 裁定落地）

- 策略：每次请求解析会话时，若**距到期 < 2 小时**，`expires_at` 顺延至 `now + SESSION_TTL_HOURS`（默认 8h，滑动窗口）；单次续期后距到期 8h，多次访问上限始终为 8h（不重排到超过 8h）。
- 不变语义：过期会话、停用账号**照旧立即失效**（`AUTH_REQUIRED`）；登出 = 立即过期（arch/00 §4 v1.1）；cookie `lexflow_session` 仍为 `HttpOnly; SameSite=Lax; Path=/`。
- 实现位置：`server/src/modules/auth/session.ts`（`resolveSession` 内联续期，写库仅在触窗时发生）。
- 运维提示：sessions 表只增不删（审计 FK），过期行清理归部署会话运维任务。

## 2. 孤儿文件清理（arch/08 §6）

- 端点：`admin.storageOrphans { confirm? }`（sysadmin 限定，非管理员同形 404）。
- dry-run（默认）：返回 storage 目录中无 `file_versions.storage_key` 引用的文件清单，写审计（`admin.storageOrphans`，`afterJson.dryRun=true`）。
- `confirm: true`：物理删除清单内文件，返回删除结果，写审计（含失败名单）。
- 用法建议：先 dry-run 复核清单 → confirm 实删；上传并发兜底（D2 同键 23505）产生的孤儿可被本任务回收。
- 审计只追加：audit_events 已有 DB 触发器禁 UPDATE/DELETE（见 §5），清理动作审计行不可篡改。

## 3. npm audit 结论（4 moderate，风险接受）

- 明细：`esbuild <=0.24.2`（GHSA-67mh-4wv8-2f99，esbuild **dev server** 任意跨源读响应）——经 `drizzle-kit 0.31.11 → @esbuild-kit/esm-loader → @esbuild-kit/core-utils` 引入，共 4 条 moderate 均为该链。
- 暴露面评估：**仅开发期工具链**。本项目 esbuild 仅被 drizzle-kit 用于迁移脚本的配置加载，不运行 esbuild dev server；生产形态（arch/08 §5）为 esbuild 打包 server / vite build app，产物不含该 dev server 代码路径。app 侧 vite 自带的 `esbuild@0.28.2` 不受影响（>0.24.2）。
- 修复路径：`npm audit fix --force` 会将 drizzle-kit 降级至 0.18.1（破坏迁移链，违反「迁移按时间序追加、禁改已提交迁移」基线）；drizzle-kit 最新版（0.31.11，已核验 npm registry）仍钉死该依赖链，无非破坏升级路径。
- **裁定建议（风险接受）**：接受 4 条 moderate，待 drizzle-kit 上游升级 @esbuild-kit 链后随常规依赖更新消除；跟踪归部署/架构会话。

## 4. CSRF 与注入面评估（arch/08 §3 矩阵结论）

- **CSRF**：会话 cookie `SameSite=Lax`——跨站 POST 不携带 cookie；API 仅接受 `application/json`（无 multipart 表单类 JSON CSRF 面），无 CORS 放开。结论：无 CSRF 面，免令牌设计成立（开发期）。
- **SQL 注入**：全部查询经 drizzle 参数化；搜索关键词为字面量绑定（探针 `'; DROP TABLE users;--` 实测定于 0 命中无异常，用例 security-iter5）。
- **枚举/字段注入**：zod 严格枚举拒绝非法值（400 VALIDATION_FAILED）。
- **越权同形**：篡改 projectId / userId（水平越权）/ 审批人 / 金额可见性 / 文件键 / 分享地址——全部 404/401 同形，无存在性泄露（用例 security-iter5 + 既有权限套件）。
