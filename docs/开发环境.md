# 开发环境从零启动

前置：Node ≥ 20、Docker（含 docker compose 插件）、Git。

```bash
# 1. 配置环境变量（按需修改 SESSION_SECRET，可用 node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" 生成）
cp .env.example .env

# 2. 启动 PostgreSQL 16（含 lexflow 与 lexflow_test 两个库）
docker compose up -d

# 3. 安装依赖（npm workspaces，单一根 lockfile）
npm install

# 4. 数据库迁移与种子（脚本由工单 02/03 实现，当前为占位）
npm run db:migrate
npm run db:seed

# 5. 启动开发服务（server + app 并行）
npm run dev
```

## 说明

- 仓库为 npm workspaces：`app/`（@lexflow/app，前端）、`server/`（@lexflow/server，服务端）、`shared/`（@lexflow/shared，前后端共享）。
- Postgres 容器端口 `5432:5432`，数据卷 `lexflow-pgdata`；`lexflow_test` 库由 `docker/postgres/init/` 在数据卷首次初始化时创建。若需重建：先 `docker compose down -v` 再 `docker compose up -d`。
- 环境变量键见 `.env.example`；`.env` 不入库。
- 质量门：`npm run typecheck`、`npm run build`、`npm run test`、`npm run db:migrate`。
