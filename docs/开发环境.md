# 开发环境从零启动

前置：Node ≥ 20、Docker（含 docker compose 插件）、Git。

```bash
# 1. 配置环境变量（按需修改 SESSION_SECRET，可用 node -e "console.log(require('crypto').randomBytes(32).toString('hex'))" 生成）
cp .env.example .env

# 2. 启动 PostgreSQL 16（含 lexflow 与 lexflow_test 两个库）
docker compose up -d

# 3. 安装依赖（npm workspaces，单一根 lockfile）
npm install

# 4. 数据库迁移与种子（drizzle 迁移只追加；种子幂等可重复执行，SEED_PROFILE=minimal|full）
npm run db:migrate
npm run db:seed

# 5. 启动开发服务（server + app 并行）
npm run dev
```

## 说明

- 仓库为 npm workspaces：`app/`（@lexflow/app，前端）、`server/`（@lexflow/server，服务端）、`shared/`（@lexflow/shared，前后端共享）。
- Postgres 容器端口 `15432:5432`（宿主机 15432 → 容器 5432；宿主机 5432 被其他项目占用，2026-10-26 裁定本仓库改用 15432），数据卷 `lexflow-pgdata`；`lexflow_test` 库由 `docker/postgres/init/` 在数据卷首次初始化时创建。若需重建：先 `docker compose down -v` 再 `docker compose up -d`。连接串见 `.env.example` 的 `DATABASE_URL` / `DATABASE_URL_TEST`（端口 15432）。
- 环境变量键见 `.env.example`；`.env` 不入库。
- 质量门：`npm run typecheck`、`npm run build`、`npm run test`、`npm run db:migrate`。

## git 远端与同步

- 远端仓库（GitHub 私有）：`git@github.com:onlyfor7/zhiyuan_OA.git`，克隆：`git clone git@github.com:onlyfor7/zhiyuan_OA.git`
- `main` 为唯一主干（受保护语义）：任何改动经工单/任务分支合入，禁止直接推 main。
- 日常同步：开工前 `git pull --ff-only` 保持 main 最新；任务分支（`<领域>/<简述>`）完成后 push 并合入 main。
- 本地全部 `iter*` 历史分支已全量推送至远端，仅作演进追溯。
