## 3. 质量与测试资产

- 自动化：**210/210 用例**（server 187 + app 23），每次交付零回归。
- E2E：**E2E-01~16 全过**（Playwright 真实浏览器，prod 栈复测深链）；安全矩阵 7/7（篡改/越权/注入/上传/会话/CSRF/方法不匹配）。
- 性能：扩充数据集（800 任务/5000 工时/2000 台账）常用查询 p95≤17ms；甘特 1000 项无 >1s 长任务；冷启动 87s 到登录可用。
- 报告：`docs/测试报告/迭代0~5-验收报告.md`（逐迭代）、`迭代5-系统验收报告.md`（总收口）、走查清单与截图（D:\tmp\shots-*）。
- 验收方法说明：逐迭代「架构会话独立复核（实弹冒烟+DB 直查）+ 测试会话收口」；迭代 3 财务域经四轮打回修复四项真实缺陷（重复票据绕过/使用态不迁移/调整单自审死锁/台账幂等键吞分录），迭代 5 生产深链 P0 修复链闭环。
