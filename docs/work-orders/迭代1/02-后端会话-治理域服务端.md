## 范围（做）

1. **审批引擎**（`services/approval/engine.ts`，arch/04 §4 接口逐字）：submit/act/withdraw/registerHandler；策略解析与角色落地为具体人；自审跳过与 `SELF_APPROVAL_BLOCKED`；`POLICY_NOT_FOUND`；步骤条件更新防并发双终态；幂等键冲突返回原实例。注册 change_request、access_grant 两个 handler。
2. **域 service + router**（arch/04 §5 清单，形态沿用 arch/02 §1/§2）：
   - project.create（模板事务生成：阶段/任务/检查项/十一目录/基线 v1 及 items；code 经 next_code；创建审计）、overview（任务/质量/决策/周报/待审批聚合，权限过滤）、成员管理、close（结项检查单：未关闭阻断质量、未完成任务、未归档周报 → 按模板配置阻断或警告，返回清单）。
   - plan：versions/current/versionGet/simulate（只算不写：依赖级联 + 关键路径影响，返回模拟结果）；transitionStage/transitionMilestone（live 状态机）。
   - task 全 CRUD+transition/assign；**无 planned_* 直改入口**。
   - change：create/update(draft)/submit/withdraw；submit 时校验原因/影响/恢复措施非空 + target_items 原日期与当前计划一致；approve 经引擎 handler 同事务生成新版本+同步 live+恢复措施生成任务+通知。
   - quality：assign/submitHandling/review/reopen；**review 强制 reviewer 身份且 severe+ 时 reviewer≠handler**（`SELF_REVIEW_BLOCKED`）；全部动作写 quality_issue_events（同事务）；退回必须 note。
   - decision：submitOpinions（按角色各写各的字段）、decide（必填四件校验+检查点生成任务）、verify。
   - report：generateDraft（真实聚合本周任务/质量/决策/延期）、updateDraft、confirm（固定版本+幂等）、再改产新版本、archive（只读+archive_links 目录 06）。
   - archive：tree/directoryItems/link/grantApply（→引擎）/grantRevoke/grantList；**文件读权限扩展**（迭代 0 留坑）：canReadFile = 上传人 ∨ 来源项目成员（经 file_objects.source_*，来源项目成员放行分支）∨ 有效 AccessGrant；grant 到期/撤销即时生效（查询时判定 expires_at/revoked_at）。
   - approval：listMine/listMineApplied/getById/act。
   - notification：事件写入接入上述各业务动作（arch/04 §6 表），聚合键防重复；listMine/unreadCount/markRead/markHandled。
   - todo.mine（并集按 §5 口径）、dashboard.summary（权限过滤聚合）、audit.list（`audit.read` 授权拦截）。
3. **遗留落地**：D2——upload 接受可选 `idempotencyKey`，命中唯一约束返回首次结果（同事务解析），探针将由测试会话翻转；N1——登录成功 resolver 显式补 actor 审计行。
4. **测试**（`tests/api/` 追加，全部连 lexflow_test）：
   - 审批引擎：完整链路（提交→步骤→终审通过→业务态迁移同事务）；并发 approve 同步骤只生效一次；同幂等键重复 submit 返回原实例；自审拦截；驳回必填理由。
   - 延期闭环：submit→approve→新 plan_version 生成 + live planned_* 同步 + 恢复任务生成 + 旧版 superseded（事务回滚用例：人为制造 handler 异常，断言无部分写入）。
   - 质量复核分离；决策四必填校验；周报确认/新版本/归档只读；grant 到期即时失效（构造过期 grant 打文件直链同形 404）；todo/通知/聚合口径断言；upload 幂等返回首次结果。
   - 迭代 0 既有 37 用例不回归。
