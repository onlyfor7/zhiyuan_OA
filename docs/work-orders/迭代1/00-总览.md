## 关键架构规则提醒（违反即打回）

1. 审批只有引擎一条实现（arch/04 §4）；延期与档案授权走引擎，质量复核与决策走各自流程。
2. planned_* 无任何直接修改入口；计划变更 = 延期申请通过 → 同事务生成新版本（PLN-I1）。
3. 台账/审计/事件表只追加；已确认/已归档对象版本化，不覆盖。
4. 审批通过 + 业务写入 + 通知 + 审计 = 同一事务；幂等键贯穿 submit/act/confirm。
5. 列表与统计 SQL 级权限过滤；无权限详情/直链同形 404。
6. 金额/分钟语义不变（本迭代基本无金额，但台账字段如出现一律 integer cents）。
