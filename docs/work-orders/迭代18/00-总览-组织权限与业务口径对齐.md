## 红线

- 不做双系统复用/拆分，不新增 `tenant_id` 或双实例占位。
- 商机成立即立项必须同事务、幂等；合同激活后沿用同一项目，禁止再建交付项目。
- 不做商机/项目双成本对象；费用继续走既有 `project_id`，按 arch/13 §5.5 公式分售前/交付。
- 权限过滤必须在服务端 SQL 层完成；不得用菜单隐藏或内存过滤替代。
- 一期不改审批引擎的 `initiator_choice` 运行时；D2 仅落地主管关系基础，完整移除归迭代 19。
- 数据会话不改业务 service/路由；架构文件只读，发现冲突回 STATUS 仲裁。
