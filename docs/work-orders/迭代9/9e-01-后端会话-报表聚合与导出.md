# 迭代 9e · 工单 01：报表聚合端点与导出（后端会话）

**依赖：** 工单 00　**产出分支建议：** `iter9e/server-reports`

## 范围

1. **权限**：注册 `report.read/report.export`（§11：read=登录全员按各数据域既有口径过滤，partner 全局只读穿透；export 同 read 口径+审计）。
2. **报表端点**（`report.*`，§8.2 九张逐字，口径复用 services 既有聚合——fin costing/台账/工时/审批/项目健康度函数，禁自写公式）：
   - 项目健康度汇总（状态×健康度矩阵）、项目进度与延期明细、项目收支核算表（直接调 9d costing 函数）、收款账龄分析（账龄分桶聚合+客户维度）、费用类别分析（类别×月度）、月度收支汇总（收/支/净额月度）、工时汇总（人/项目/部门三视角）、人员利用率（批准工时/可用工时）、商机漏斗（阶段×数量×金额）、客户贡献排行（合同额/回款额 Top）。
   - 统一入参：日期区间/部门/项目/客户筛选；统一出参：{columns, rows, summaryCards}。
3. **导出**：`report.exportCsv`——服务端生成 CSV → file_objects(source_type=report)+版本 → 返回下载令牌（既有 HMAC 管道），审计同事务（动作 report.export 含报表 key+筛选快照）。

## 验收

九报表口径抽样重算勾稽（与台账/costing 一致）；权限探针（member 只见本人口径/partner 全局）；导出文件可下载+审计行；根四道门全绿；e2e 不回归。**F3 套件独占。**

**完成动作：** STATUS 工单行+交接记录。
