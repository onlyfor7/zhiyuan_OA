# 迭代 9a · 工单 04：生产加固小包（后端会话 · 微工单）

**依赖：** 9a-03 通过　**产出分支建议：** `iter9a/prod-hardening`
**契约：** arch/12 §14（v1.1，用户裁定 50–100 并发生产基线）

## 范围（做）

1. **连接池显式化**（`server/src/db/client.ts`）：`max: 20`、`idleTimeoutMillis: 30000`、`connectionTimeoutMillis: 5000`（获取超时显式报错，杜绝挂起）；值读 env，默认如上。
2. **statement_timeout**：连接级 15s（pool connect 钩子 `SET statement_timeout`），跑飞查询快速失败。
3. **慢查询日志**：单查询 >500ms 记 warn（含 requestId）。
4. **登录限流**：`auth.login` 同 IP+账号 5 次/分钟，超限 429（既有统一错误形状，不泄账号存在性）；内存滑动窗口即可（单进程），键=`ip|email`。
5. **安全响应头**：X-Frame-Options DENY、X-Content-Type-Options nosniff、Referrer-Policy: same-origin、基础 CSP（default-src 'self'，按需放行同源资产/图片 blob）。
6. **会话/审计保留期配置键**：`security.session_retention_days`（90）、`audit.retention_days`（730）入 system_config 白名单与种子（清理任务本体属运维手册，不在本工单实现清理）。

## 验收（逐条）

- 新用例：连接池参数生效（pool.options 断言/env 覆盖）、登录限流第 6 次 429、安全头四件在响应、超时语句被 15s 截断（`pg_sleep(16)` 探针，测试环境临时调低阈值验证）。
- 回归：server 全量 + 根四道门全绿（注意 06b threads 池下验证）；e2e-01~16 不回归。
- prod 发布：重建 server 镜像（`DOCKER_BUILDKIT=0 --no-cache`）复起，不删卷；实测登录限流与安全头在 :8080 生效。
