# 迭代 9d · 工单 02：财务核算服务端（后端会话）

**依赖：** 工单 01 通过　**产出分支建议：** `iter9d/server-fin`

## 范围

1. **权限**：注册 `fin.read`（finance/partner/项目负责人本项目管理口径）与 `fin.manage`（finance/partner）；member 财务域 404 同形（本人费用端点不破）。
2. **应收**：`fin.receivables.list`（账龄分桶 computed：0-30/31-60/61-90/90+，逾期=当前超 due+grace）、`fin.receivables.generate`（合同激活/计划到期自动生成，幂等防重）、收款登记/作废勾稽应收（同事务 partial/settled 写回，与 9c 计划行写回同事务链一致）。
3. **发票**：`fin.invoices.list/create/issue/markSent/void`（红冲=voided+冲正行；开具可联动应收带出金额/税率/抬头——抬头取 company_profile）。
4. **成本率**：`fin.costRates.list/upsert`（fin.manage；member 不可见金额）。
5. **项目核算**：`fin.projectCosting.get/list`——按 §7.3 冻结公式聚合（收入/已回款/应收余额/直接成本/人力成本/毛利双口径），口径只在 server services 一处（报表域复用同一函数）。

## 验收

应收生成幂等+勾稽写回+红冲+核算公式重算勾稽用例；权限三探针；根四道门全绿；e2e 不回归。

**完成动作：** STATUS 工单行+交接记录。
