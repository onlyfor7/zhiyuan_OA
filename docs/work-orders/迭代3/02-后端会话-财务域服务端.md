# 迭代 3 · 工单 02：财务域服务端（后端会话）

**依赖：** 工单 01 通过（串行第 2 棒）　**产出分支建议：** `iter3/server-finance`
**契约：** `docs/arch/06-迭代3-预算经费费用域契约.md` §3–§8 逐字实现；本迭代红线见工单 00「红线提醒」

## 范围（做）

1. **台账服务**（`services/ledger/record.ts`，**唯一写入者**）：record(tx, entry)——幂等键 `entryType:sourceId:seq`、唯一约束兜底、重放返回已存在分录；聚合查询函数（有效预算/有效占用/实际支出/可用额度/执行率，hasBudget 语义）。
2. **预算域**：create（含类别行）/submit/withdraw/approve 经引擎（biz_type='budget'，通过同事务写 BUDGET_ACTIVATED）；adjust（产新 draft 版本→审批→active+旧 superseded+BUDGET_ADJUSTED 前后值）；close；getById 台账聚合+下钻；ledger 明细查询。
3. **经费域**：create/update/submit/withdraw；approve 同事务 FUNDING_RESERVED（只一次）；close（检查项：未决报销阻断、未用额度先释放）；releaseUnused；getById 四数（获批/已关联费用/已核销/未使用）全部可由台账+明细重算。
4. **费用域**：create（items[]，**合计服务端计算**，跨项目明细逐行鉴权）、update(draft)、submit（§5 检查项+重复票据检查，快照随审批保存）、withdraw、attachReceipt（票据附件继承费用权限）；**核销事务**（arch/06 §4.3 逐字：RELEASED+RECOGNIZED 同事务、超额进实际+超预算检查、无双扣）；markPaid（finance，登记支付日期+参考号，paid 不可编辑）；adjustCreate（调整单走引擎，通过写 EXPENSE_ADJUSTED）。
5. **统计与导出**：byProject/byCategory/byPerson（标注 asOf+statusScope，口径 §4.5）；exportCsv（服务端生成、权限过滤、audit 导出事件）。
6. **集成**（§8）：项目总览预算摘要、工作台我的申请卡、驾驶舱预算执行/费用（角色过滤）、周报费用节、归档（经费获批→11 目录；报销获批含票据→10 目录）、出差完成页报销入口数据预填、预算超限通知。
7. **权限**：canReadFile 增 expense 票据分支（申请人/审批人/财务）；财务不见法律内容（E2E-12）。
8. **测试**：C1–C11 可自动化部分全覆盖（重点：核销事务回滚零部分写入、幂等键重放、双扣检测断言、重复票据三种命中、超预算 block/escalate 两策略、支付后编辑被拒、调整净额）；既有 120 用例零回归。
