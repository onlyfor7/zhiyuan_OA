# 迭代 3 · 工单 03：财务域前端接入（前端会话）

**依赖：** 工单 02 通过（串行第 3 棒）　**产出分支建议：** `iter3/frontend-finance`
**契约：** `docs/arch/06-迭代3-预算经费费用域契约.md` §7/§8；设计沿用三区与设计系统

## 范围（做）

1. **经营中心**（新导航组）：`/operations/budget`（预算列表+执行横条：实际/占用/可用三段+数值文字并列，不只依赖颜色——基线 §13.4）、`/operations/expenses`（费用中心列表+统计筛选+导出入口）、`/operations/funding/:id` 经费详情（四数卡+台账下钻）。
2. **项目空间**：「预算经费」「费用」页签接真实数据（替换 NotConnected）；总览加预算执行摘要卡（可下钻台账）。
3. **表单**：经费申请（金额元→分换算、用途必填、关联会议/出差可选）；报销单（明细编辑器：日期/类别/金额/说明/支付对象/票据上传带幂等键、票据必填类别强校验；**合计只读展示服务端计算值**；跨项目明细拆分编辑）；预算创建/调整（调整必填原因+影响）；支付登记 modal（参考号必填）。
4. **审批中心**：接入 budget/funding/expense/expense_adjustment 新 biz 类型（审批快照含检查项与前后值展示）。
5. **经费关闭**：关闭前检查项清单展示（未决报销阻断提示、未用额度释放确认）。
6. **调整/冲销**：已支付报销的更正入口（调整单表单+审批进度）。
7. **工作台/驾驶舱**：我的申请状态卡（经费/报销）、预算执行摘要（角色过滤）。
8. **出差详情**：「发起报销」按钮接通 expense.create 预填（替换迭代 2 的提示）。
9. 权限呈现：成员不见财务汇总（页签不显示或脱敏占位，不泄露数字）；finance 视图按其职责。
10. 表单规范沿用（幂等键、防重复提交、STATE_CONFLICT 保留输入）；375px 无整页横向溢出（台账横条与表格注意）。
