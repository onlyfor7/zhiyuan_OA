## 范围（做）

1. **server 生产构建**：esbuild 打包 `server/src/index.ts` → `dist/index.js` 单文件（shared 打入、原生依赖 external）；`server/package.json` `build` 替换为真构建（兑现 arch/00 §2 v1.1 占位语义）、新增 `start`；typecheck 门保留。迁移文件需随产物可用（drizzle migrate 在容器启动时或独立 job 执行——自决并文档化）。
2. **app 生产构建**：`vite build` 静态产物 + nginx 配置（静态服务 + `/trpc`/`/files` 反代 server）。
3. **`docker-compose.prod.yml`**：postgres:16 + server + web 三服务，健康检查、命名卷、环境变量注入、端口规划（不与开发冲突）；`.env.production.example`（密钥占位+生成指引，禁止真值入库）。
4. **备份恢复**：`scripts/backup.sh`（pg_dump + storage 打包）与 `scripts/restore.sh`（恢复后校验：台账行数、审计行数、文件 sha256 抽样）；文档化 RPO/RTO。
5. **文档**：`docs/部署手册.md`——从零部署步骤、配置项表、备份恢复、升级与迁移流程、故障排查。
6. **验证**：生产 compose 起栈成功（三服务 healthy）；备份→删库→恢复→校验通过（演练实录写交接记录）；冷启动计时。

## 不做

不改业务代码（构建问题→STATUS 登记回退对应会话）；不上云（真实部署属律所环境）。
