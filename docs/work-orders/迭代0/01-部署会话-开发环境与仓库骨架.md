## 范围（做）

1. `git init`（仓库根 `Kimi_Agent_律所项目管理平台/`），创建根 `.gitignore`：`node_modules/`、`dist/`、`.env`、`server/storage/`、`*.log`、`.DS_Store`。首个 commit：`[部署] 初始化仓库`。
2. 创建 npm workspaces 骨架，**严格按 `docs/arch/00-技术基线与目录结构.md` §2**：
   - 根 `package.json`（内容以 arch/00 §2 代码块为准）、`tsconfig.base.json`（`strict: true`、`moduleResolution: "bundler"`、`target: ES2022`、`paths: { "@lexflow/shared": ["./shared/src/index.ts"] }`）。
   - `shared/`：`package.json`（`name: @lexflow/shared`，`main: src/index.ts`，peer 依赖 zod ^4）、`src/index.ts` 空 barrel、tsconfig。
   - `server/`：`package.json`（`name: @lexflow/server`，脚本占位 `dev/typecheck/test/db:generate/db:migrate/db:seed`，内容空实现留给后端/数据会话填）、tsconfig。
   - 改 `app/package.json` 的 `name` 为 `@lexflow/app`，加脚本 `typecheck: tsc -b --noEmit`；**删除 `app/package-lock.json`**（统一根 lockfile）。
   - 根目录 `npm install` 一次，确认 workspaces 解析成功。
3. `docker-compose.yml`：`postgres:16` 服务，环境变量取自 `.env`（`POSTGRES_USER=lexflow`、`POSTGRES_PASSWORD` 来自 env、端口 `15432:5432`），命名数据卷，healthcheck `pg_isready`；用一个初始化脚本或启动后命令建第二个库 `lexflow_test`（供测试会话）。
4. `.env.example`：`DATABASE_URL=postgres://lexflow:lexflow_dev@localhost:15432/lexflow`、`DATABASE_URL_TEST=postgres://lexflow:lexflow_dev@localhost:15432/lexflow_test`、`SESSION_SECRET=<请生成32字节随机>`、`STORAGE_DIR=./server/storage`、`PORT=3001`、`SESSION_TTL_HOURS=8`。

> **端口裁定（2026-10-26，用户裁定，架构会话吸收进基线）：** 宿主机 5432 被其他项目容器（jtl-postgres）长期占用，lexflow 的 Postgres 宿主端口固定为 **15432**。全项目所有会话连接数据库一律 `localhost:15432`。本工单原文 5432 已按裁定修订。
5. 根 `README.md` 追加（不删原有内容则新建 `docs/开发环境.md`）：从零启动步骤——`docker compose up -d` → `npm install` → `npm run db:migrate` → `npm run db:seed` → `npm run dev`。
