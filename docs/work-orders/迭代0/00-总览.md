## 迭代验收场景（测试会话执行，全部通过才收口）

1. `pm@lexflow.demo` 与 `member@lexflow.demo` 登录后，`project.list` 返回的项目集合不同（member 不含未加入项目）。
2. member 直接访问未授权项目详情直链 → 统一 `NOT_FOUND` 形态，前端显示 403/404 页，不泄露项目是否存在。
3. 未授权用户获取他人上传文件的下载地址 → 服务端拒绝（403/404 同形）；授权用户可下载且内容 sha256 一致。
4. 刷新页面、重新登录后数据一致；登出后所有 API 返回 `AUTH_REQUIRED`。
5. 停用某账号后其会话立即失效。
6. 八视图在路由下可访问且视觉无回归；未接入数据的统计区域显示「未接入」占位，无任何假数据。
7. 干净库上 `db:migrate` 重放成功、`db:seed` 幂等；变更类请求产生 `audit_events` 行。
