# 迭代 0 · 工单 03：服务端地基（后端会话）

**依赖：** 工单 02 通过（串行第 2 棒：表结构与种子已就绪，直接对真实库开发与联调）　**产出分支建议：** `iter0/server-foundation`

## 范围（做）

1. 依赖（server workspace）：`hono`、`@hono/node-server`、`@hono/trpc-server`、`@trpc/server`、`zod`。
2. 骨架（arch/00 §2 目录）：`env.ts`（zod 校验环境变量）、`index.ts`（Hono app，`/trpc/*` 挂 tRPC，`/files/*` 挂文件路由，`/health` 返回 `{ ok: true }`）。
3. **认证**（arch/00 §4）：`modules/auth/`——login（scrypt 校验，复用数据会话 `lib/password.ts`；失败统一提示）、logout（删服务端会话）、会话中间件（cookie → session → `ctx.user` 含全局角色与项目成员关系）。cookie 名 `lexflow_session`，HttpOnly/SameSite=Lax。账号 disabled 或会话过期 → `AUTH_REQUIRED`。
4. **权限服务**（arch/03）：`services/access/`——`can(user, action, resource)` 与 `projectScopeFilter(user)`（返回 SQL 条件：本人是成员的项目 + 有效授权）；迭代 0 实现 `project.read`、`archive.read`（文件）、`admin.config` 三个动作的判定，其余动作先注册后拒绝（默认 deny）。
5. **审计**（arch/02 §7）：`services/audit/record()` + tRPC 变更类中间件自动写 `audit_events`；与业务写同事务（事务经 `db.transaction` 传递）。
6. **tRPC routers**（按 arch/02 §4 冻结契约，逐字实现）：`auth.login/logout/me`、`project.list`（游标分页 + SQL 级权限过滤）、`project.getById`（无权限返回 `ACCESS_DENIED_OR_GONE`）、`user.listProjectMembers`。导出 `AppRouter` 类型供前端消费。
7. **文件路由**（arch/00 §5）：`routes/files.ts`——上传（白名单+20MB+sha256+storage_key 防穿越）、download/preview（session 或 ≤15min 令牌鉴权；无权限与不存在同形 404）。`services/file/` 与 web 层分离。
8. **统一错误**（arch/02 §6）：zod 错误 → `VALIDATION_FAILED` 字段映射；兜底 `INTERNAL` 带 requestId 无堆栈；响应错误形状前后端一致。
9. 测试 `server/tests/api/`（直连 `app.request`，用 `lexflow_test`）：登录/登出/me 全流程；`project.list` 两账号范围不同；member 直取项目 C 详情 → NOT_FOUND 同形；无授权下载他人文件 → 拒绝；变更产生审计行；停用账号会话失效。

## 不做

不写任何业务审批流；不建迭代 1+ 模块的 router 空壳；不改 shared 已有内容（缺枚举在 STATUS.md 登记需求）。
