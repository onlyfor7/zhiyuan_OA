# 迭代 0 · 工单 02：地基数据建模与种子（数据会话）

**依赖：** 工单 01（骨架 + Postgres）　**产出分支建议：** `iter0/data-foundation`

## 范围（做）

1. 安装依赖（server workspace）：`drizzle-orm`、`drizzle-kit`(dev)、`pg`、`zod`。
2. `server/drizzle.config.ts` + `server/src/db/client.ts`（连接池读 `DATABASE_URL`）。
3. **建表：`docs/arch/01-数据模型与状态机.md` §1「迭代 0」全部 15 张表**，逐表落实：
   - 通用字段按 §2（含 `row_version`、审计四件套）；枚举按 §3 用 pgEnum（迭代 0 需要的：用户状态、密级、项目生命周期/健康度、授权状态）。
   - `code_sequences` 的事务内自增函数 `next_code(prefix)`（`server/src/db/code.ts`）：`INSERT … ON CONFLICT DO UPDATE next_value+1 RETURNING`，并发安全。
   - 索引与约束按 arch/01 §6；外键默认 `ON DELETE RESTRICT`。
   - `audit_events`：ORM 层只提供 insert，不提供 update/delete。
4. `drizzle-kit generate` 产出首个迁移；`db:migrate`（drizzle migrate）、`db:seed` 脚本接入 server workspace 脚本。
5. `shared/src/`：按 `arch/02 §3` 建 `enums/`（迭代 0 所需枚举先落：角色 key、密级、项目生命周期/健康度、授权状态）、`constants.ts`（编号前缀表）、`errors.ts`（arch/02 §6 全部错误码常量）、`permissions.ts`（动作注册表，arch/03 §3 全量动作可先注册）。
6. 种子 `server/src/db/seed/index.ts`（幂等：可重复执行不产生重复行）：
   - 组织树（1 律所 + 3 部门）、8 角色（arch/03 §1）、≥10 用户（口令统一 `Demo@2026`，scrypt 散列——散列函数若后端会话未交付，先在 `server/src/lib/password.ts` 自实现，后端会话复用）、用户角色分配。
   - 2 客户、2 事项、3 项目：`pm@lexflow.demo` 是项目 A/B 负责人；`member@lexflow.demo` 仅是项目 A 成员；项目 C 对二者均不可见（验收场景依赖此布局，详见工单 00 §迭代验收场景 1/2）。
   - `system_config` 写入需求基线 §18 全部默认配置项。
7. 测试 `server/tests/db/`：干净 `lexflow_test` 库重放迁移成功；`next_code` 并发 20 次无重号；seed 二次执行行数不变。

## 不做

不建迭代 1+ 的表（tasks/meetings/budget… 一律不建）；不写 tRPC router；不动 `app/`。

