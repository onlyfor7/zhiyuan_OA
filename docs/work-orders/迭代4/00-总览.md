## 红线提醒（违反即打回）

1. 工时一律整数分钟；禁止浮点小时反复累加。
2. 单日 >24h 阻止必须跨周期合并计算（同日两条周期拆分绕过是典型漏洞）。
3. 预填/复制一律草稿态：可编辑、默认未提交、不进任何有效工时统计。
4. 周期批准后明细只读；locked 普通修改禁止；unlock 专门权限+理由+审计。
5. 搜索 SQL 级过滤先于组装；无权限不泄露标题/金额；命中计数按可见集合。

## 不做

费率/人力成本（TIM-010 关闭）；客户计费；考勤；P1 项（重复会议/日历同步/出差报告模板）。
