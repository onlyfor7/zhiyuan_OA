# 迭代 6 · 工单 03：扩展域服务端（后端会话）

**依赖：** 工单 02 通过　**产出分支建议：** `iter6/server-extensions`
**契约：** `docs/arch/09-迭代6-扩展域契约.md` §2–§4 逐字实现

## 范围（做）

1. **收款域**（`modules/receipts/`）：list/getById/create（finance，幂等）/void（理由+审计，registered 行不改金额）/summary（byProject/byClient/byPeriod，口径=registered−voided 原额）/exportCsv（审计）；权限：finance 写、partner 范围读、pm 本项目读、member/viewer 不可见；附件继承财务权限；项目总览/驾驶舱接入收款摘要。
2. **流程引擎升级**（`services/approval/`）：flow 定义编译——按 biz_binding 取 enabled 流程 → 条件求值（表单快照）→ 展开 approval_steps（含条件结果）→ policy_snapshot 存流程版本+解析步骤；无自定义流程时回退默认流程；既有 biz_type 全兼容不回归；flow.list/createDraft/updateDraft/publish/disable/versions（服务端校验：环/悬空/start-end 唯一/条件双边/自审全跳过阻断发布 FLOW_UNPUBLISHABLE）。
3. **通用申请单**（`modules/requests/`）：全 CRUD+submit/withdraw（引擎 biz_type='generic_request'，global scope 流程）；审批中心节点图进度数据（当前节点+路径回放）。
4. **admin.* 域**：用户（创建含初始口令+首登强制改密/停用/启用/角色分配）、客户/事项 CRUD（停用非删除）、模板编辑（structure 校验）、config get/set（白名单键+前后值审计）；全部 admin.config 门+审计。
5. **自助改密**：`auth.changePassword`（验旧+全会话失效+审计）。
6. **测试**：E1–E8 可自动化部分（arch/09 §6）；既有 210 用例零回归（既有审批行为兼容用例必须全绿）。
