# 用户自助测试手册

**版本：** v1.0（2026-10-30，工单 10）　**适用系统：** LEXFLOW 律所项目治理平台 prod 栈 http://localhost:8080
**编写方式：** 测试会话已在现网（干净 minimal 态）逐页实走核对，本文所有按钮名/页面名/输入占位与现网一致。
**怎么用：** 按篇顺序照做即可；每步给出「预期结果」与「验收点」，看到验收点描述的内容即为通过，在文末验收记录表打勾。数据示例全部虚构，金额单位是**元**（系统内部按分记账，对账时以元读数）。

## 一、准备篇

### 1.1 环境入口

- 地址：**http://localhost:8080**（推荐 Chrome/Edge 最新版，窗口尽量大）。
- 左侧固定导航 8 项：**01驾驶舱 / 02我的工作台 / 03项目全周期 / 04甘特计划 / 05质量中心 / 06决策中心 / 07档案中心 / 08权限审计**，底部有「查看全部项目」。
- 顶部有全局搜索框（占位「搜索项目、任务、报销、文件」，快捷键 ⌘K）与通知铃铛。
- 会话有效期 **8 小时**；**用户被停用即刻失效**；改密后所有端全部失效。

### 1.2 角色账号口令表（统一口令 Demo@2026）

| 角色 | 账号 | 身份说明 | 主要阵地 |
|---|---|---|---|
| 合伙人（负责人） | partner@lexflow.demo | 周正，全局最高业务角色 | 驾驶舱/立项/审批/结项 |
| 项目负责人 | pm@lexflow.demo | 陈立，项目日常管理 | 项目空间/审批/成员 |
| 项目成员 | member@lexflow.demo | 林晓，干活的人 | 工作台/任务/报销/工时 |
| 财务 | finance@lexflow.demo | 吴敏，钱的事 | 收款/费用/核销/支付 |
| 档案管理员 | archivist@lexflow.demo | 授权审批人 | 档案中心/授权队列 |
| 质量负责人 | quality@lexflow.demo | 质量复核 | 质量中心 |
| 系统管理员 | sysadmin@lexflow.demo | 配置与账号 | /admin/审计 |
| 只读查阅人 | viewer@lexflow.demo | 外部/实习只读 | 被授权后看项目 |

### 1.3 登录 / 登出 / 自助改密

| 步骤 | 操作 | 预期 | 验收点 |
|---|---|---|---|
| 1 | 打开 http://localhost:8080，自动跳到登录页 | 见「登录」标题与两个输入框 | 占位分别为「name@firm.com」「请输入密码」 |
| 2 | 输入账号与 Demo@2026，点「登录」 | 进入左侧导航主页 | 左上角 LEXFLOW 标识 + 8 项导航 |
| 3 | 右上角头像菜单「退出登录」（或 /settings 页） | 回到登录页 | 再访问任何页面都被弹回登录 |
| 4 | /settings「自助改密」：输入新密码点「确认修改（改后需重新登录）」 | 提示需重新登录，旧会话全失效 | 用新密码能登录、旧密码不能 |

> 换角色测试时务必先退出再登录；同一个浏览器同时只有一个生效会话。

### 1.4 各角色能看什么（速查，详细矩阵见第五章）

- **partner / sysadmin**：几乎全站可见；sysadmin 多一个 /admin 配置中心。
- **pm / member**：自己参与的项目 + 工作台 + 工时；看不到财务金额明细（同形 404）。
- **finance**：收款/费用中心可见，项目列表不可见（不在项目里时）。
- **archivist / quality**：各自中心可见，无项目访问权。
- **viewer**：只能看被授权的项目（授权前访问任意项目 = 404 同形页面）。
