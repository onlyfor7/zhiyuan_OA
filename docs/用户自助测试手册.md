# 用户自助测试手册

**版本：** v1.8（2026-11-07，v1.7 + 迭代 10 体验打磨同步）　**适用系统：** 因诺智元业务管理平台 prod 栈 http://localhost:8080
**编写方式：** 测试会话已在现网逐页实走核对；v1.8 按迭代 10 修订——新增 T4n 多页签工作区章 + §4.5/§4.6/§5/H2/报表风格六裁定映射速览。报表中心自 v1.7 沿用。
**怎么用：** 按篇顺序照做即可；每步给出「预期结果」与「验收点」，看到验收点描述的内容即为通过，在文末验收记录表打勾。数据示例全部虚构，金额单位是**元**（系统内部按分记账，对账时以元读数）。

## 一、准备篇

### 1.1 环境入口

- 地址：**http://localhost:8080**（推荐 Chrome/Edge 最新版，窗口尽量大）。系统品牌=**因诺智元业务管理平台**（登录页/顶栏/浏览器标题均为新品牌，旧 LEXFLOW 字样已全部替换）。
- **顶栏导航（迭代 9a 八组级联气泡）**：左→右为 `因诺智元业务管理平台 │ 总览 ▾ │ 客户 ▾ │ 项目 ▾ │ 协同 ▾ │ 经营 ▾ │ 报表 ▾ │ 办公 ▾ │ 治理 ▾ │ ⌘K 搜索 │ 铃铛 │ 头像 ▾`。鼠标悬停（约 0.1s）或点击组名 → **悬浮气泡面板**贴顶栏下缘弹出，不推挤页面内容；hover/选中二级项 → 右侧飞出三级面板（键盘同样可达：Enter 开、↑↓ 移动、→ 进子级、Esc 关且焦点回组按钮）：
  - **总览 ▾**：驾驶舱、我的工作台、通知中心、全局搜索
  - **客户 ▾**：线索与商机（线索池/商机管理/跟进记录）｜客户与合同（客户列表/合同管理）——**本轮为「即将上线」占位卡**，可点入看占位说明
  - **项目 ▾**：项目全周期、新建项目（分步 Stepper）、项目模板
  - **协同 ▾**：会议与出差（会议/出差）｜审议与质量（审批中心/决策/质量）
  - **经营 ▾**：预算与费用（预算经费/费用报销/经费申请）｜收款与核算（收款台账/应收管理/发票管理/项目核算）｜工时中心
  - **报表 ▾**：报表目录（报表工作台）+项目类/财务类/人事工时类/客户类报表——占位卡
  - **办公 ▾**：我的申请单
  - **治理 ▾**：档案与审计（档案总库/权限审计）；组织管理（公司信息/部门维护/员工信息）与系统配置（审批流中心/项目模板/编号与字典/系统参数）**仅 sysadmin 可见**
- **没有左侧栏**（IA v2 沿用）：看项目走「项目 ▾ → 项目全周期」列表→点项目名进空间。
- **系统级入口**：头像 ▾=账户信息/修改密码/界面自定义（密度选择对话框，偏好存本机）；**退出登录在 账号设置页**。
- 无权限的菜单项**不渲染**（不是置灰）。
- 桌面任意页面**无页面级滚动条**（内容在模块内滚动/分页；375px 手机单列滚动属正常例外）。
- 会话有效期 **8 小时**；**用户被停用即刻失效**；改密后所有端全部失效。

### 1.3 登录 / 登出 / 自助改密

| 步骤 | 操作 | 预期 | 验收点 |
|---|---|---|---|
| 1 | 打开 http://localhost:8080，自动跳到登录页 | 见「登录」标题与两个输入框 | 占位分别为「name@firm.com」「请输入密码」 |
| 2 | 输入账号与 Demo@2026，点「登录」 | 进入顶栏六组导航主页 | 总览/项目/协同/经营/治理/办公 + ⌘K + 铃铛 + 头像 |
| 3 | 头像 ▾→「账号设置」（或 /settings）页内「退出登录」 | 回到登录页 | 再访问任何页面都被弹回登录 |
| 4 | /settings「自助改密」：输入新密码点「确认修改（改后需重新登录）」 | 提示需重新登录，旧会话全失效 | 用新密码能登录、旧密码不能 |

> 换角色测试时务必先退出再登录；同一个浏览器同时只有一个生效会话。

### 1.4 各角色能看什么（速查，详细矩阵见第五章）

- **partner / sysadmin**：六组菜单几乎全可见；sysadmin 的「治理」组多「系统配置中心」入口。
- **pm / member**：自己参与的项目 + 总览/协同/经营（部分项按角色过滤）；member 看不到「权限审计」「收款台账」，看不到财务金额明细（同形 404）。
- **finance**：经营组的「收款台账」「费用中心」可见；治理组无「权限审计」；项目列表不可见（不在项目里时）。
- **archivist / quality**：治理组各自中心可见，无项目访问权。
- **viewer**：只能看被授权的项目（授权前访问任意项目 = 404 同形页面）。
- 无权限的菜单项**不渲染**（不是置灰），看不到即无入口。
