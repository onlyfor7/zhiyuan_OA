## 四、脚本适配与口径记录（非应用缺陷）

| 适配/口径 | 理由 |
|---|---|
| nav-dialog 事件通道开经费弹窗 | 级联三级 hover 在 Playwright 下两度致 Chrome 渲染进程崩溃（D-12-4-4 环境坑）——改用叶项同机制 `lexflow:nav-dialog` CustomEvent；级联行为本身 9a/12-01 已验 |
| 全局禁动画注入 | 小元呼吸动画（无限 scale）使 Playwright click 永不 stable；统一 `animation/transition/backdrop-filter: none` 注入后 dispatchEvent 驱动 |
| create 不自动提审 | 经费单创建=草稿（创建并查看→详情），提审走 funding.submit——与 11-02 教训同口径；A1 确认环断言落在「复核后 submit 落地」 |
| 限流窗口 20 次/分跨调试run累积 | askXiaoYuan 内置 429 检测+65s 冷却重试一次（限流本身为被测特性，非缺陷） |
