# 迭代 5 · 试用剧本（供项目方真人试用）

**产出：** 测试会话　**日期：** 2026-10-28　**环境：** http://localhost:8080（生产栈，nginx 同源）或 http://localhost:3000（开发栈）；账号口令统一 `Demo@2026`
**用法：** 每角色按序执行 5–8 个任务；记录完成时间、卡点、缺陷于文末记录表；发现异常先截图（含地址栏与账号）再反馈。当前生产栈多级深链白屏（已登记偏差待修复），试用请从单段入口进入后靠页面内跳转，或直接用开发栈。

## 一、合伙人（partner@lexflow.demo）
1. 驾驶舱查看项目组合脉搏、待审批数、本周会议/出差中/已批准工时卡（预期：真实聚合+asOf 时间戳）。
2. 审批中心通过一件 key 级延期申请（预期：步骤进度可见，通过后项目计划版本 V+1 生效）。
3. 对项目 A 发起预算调整 +500 元（预期：产新 pending 版本，你终审后生效）。
4. 解锁一件已锁定工时周期（预期：理由必填，审计留痕）。
5. 用顶栏搜索「报销」（预期：费用结果带金额——财务可见权）。
6. 375px 窗口打开驾驶舱（预期：汉堡菜单导航全部视图可达，无横向滚动条）。

## 二、项目负责人（pm@lexflow.demo）
1. 项目空间总览直开（预期：任务总数/成员/治理要点/预算摘要真实渲染——潜伏崩溃已修复）。
2. 计划页签发起书面延期（原因/影响/恢复措施+检查点）→ 提交 → 看版本横幅变化。
3. 质量页签登记 severe 问题并分派处理人/复核人（预期：同一人复核被拦）。
4. 决策页签完成一件双意见决策（预期：双意见不齐 decide 被拦）。
5. 工时中心提交本周工时 → 看审批人解析（预期：负责人工时上级审批=partner，不自审）。
6. 结项检查（预期：阻断/警告清单明确列出）。

## 三、项目成员（member@lexflow.demo）
1. 工作台待办卡片处理一件逾期任务（预期：处理后卡片消失）。
2. 会议详情一键预填工时（预期：仅草稿、提示不计有效工时；重复预填幂等）。
3. 填报工时时故意同日录 1500 分钟（预期：被拦「单日合计超 24h」）。
4. 提交报销并上传票据；再用同号同额提交一次（预期：重复票据被拦并显示原报销单号）。
5. 搜索「华宸」（预期：只见自己权限内项目，无金额字段）。
6. 出差申请（含借款）→ 看 pm+finance 会签两步审批。

## 四、财务（finance@lexflow.demo）
1. 费用中心看全量报销并导出 CSV（预期：含票据号、口径标注；导出有审计）。
2. 对 approved 报销登记支付（预期：仅 finance 可；参考号必填）。
3. 对 paid 报销发起调整 −50 元（预期：partner 终审后台账净额变化、原记录不变）。
4. 尝试打开项目 A 详情页（预期：同形 404——不因此获得法律内容权）。
5. 经费详情看四数卡（已获批/已关联/已释放/净占用）与台账下钻（预期：全服务端重算）。

## 五、档案管理员（archivist@lexflow.demo）
1. 审批一件档案授权申请（预期：通过后申请人立即可读）。
2. 撤销一件有效授权（预期：即时失效，申请人直链回同形 404）。
3. 档案中心查看 09/10/11 目录自动归集（会议纪要/出差材料/经费）。
4. 审计页筛选导出事件（预期：audit.read 权限内可查全表）。

## 六、质量负责人（quality@lexflow.demo）
1. 质量中心处理一件 severe（提交处理→pm 复核通过→关闭）。
2. 决策页签提交质量意见（预期：按角色各写各的）。
3. 检查清单逐项勾选（预期：状态留痕）。
4. 看根因/分级筛选与阻断标识（预期：critical/severe 未关闭显示阻断）。

## 七、系统管理员（sysadmin@lexflow.demo）
1. 审计页按操作者筛选（预期：过滤精确）。
2. 存储孤儿清理 dry-run（GET /trpc/admin.storageOrphans，预期：只读清单）→ purge（预期：实删+审计）。
3. 成员管理/角色配置入口查看（预期：sysadmin 可配置但不默认读业务内容）。

## 八、只读查阅人（viewer@lexflow.demo）
1. 登录后看项目列表（预期：空——默认不见）。
2. 搜索任意关键词（预期：零命中，无任何标题泄露）。
3. 直链项目 A（预期：同形 404 页）。
