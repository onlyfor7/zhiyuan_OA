## 六、脚本适配记录（非应用缺陷）

| 适配 | 理由 |
|---|---|
| 行选择器 `:scope > *`（非 `> span`） | 应收管理客户格为 `<strong>`，`> span` 漏格致假阳性 524px |
| 居中格度量改比中心 | 状态徽标 justify-self:center 系裁定要求，比盒缘必假阳 |
| 审批造数 create+getById+submit 三段 | create 响应无 rowVersion（id/code/totalCents 三字段），submit 必备；申请单流程含「发起人指定审批人」节点须传 chosenApproverId（user.list 参照取 finance 人） |
| formSnapshot 仅部分字段 | expense=checks/travel=borrow+cost——实例行按 bizType+提交新鲜度匹配，不按事由 |
| /login 页作错误态活体载体 | 发票抽屉空提交钮为禁用式校验；登录页 react-hook-form field-error 红字为既有规范活体；红环以样式表规则断言 |
| T1 采样页替换 | 收款台账/费用报销/项目列表非网格表（卡片/看板结构），换 CRM 四页+fin 两页（全网格表真实载体） |
